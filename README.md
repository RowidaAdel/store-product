# 🛒 Store Product

A responsive online store built with **HTML, CSS, and vanilla JavaScript**. Products are fetched dynamically from an API using the Fetch API and rendered on the page.

🔗 **Live Demo:** https://rowidaadel.github.io/store-product/

## ✨ Features

- Fetch products from an API using `fetch`
- Dynamic product cards (image, title, price, description)
- Product details page
- Shopping cart page
- Responsive layout for mobile, tablet, and desktop

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API

## 🚀 Run Locally

```bash
git clone https://github.com/RowidaAdel/store-product.git
cd store-product
```

Then open `index.html` in your browser (or use the Live Server extension in VS Code).
